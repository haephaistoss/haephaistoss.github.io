## What I Work On

- **[Lasthavens AddOn & LAN Bridge](https://github.com/haephaistoss):** Companion daemon (macOS, Windows, Linux) and Chrome extension that synchronizes local 3.3.5a AddOns and WTF profiles into browser-based WebAssembly game clients with LAN multi-device sharing.
- **[LoginScreen-by-Mordred](https://github.com/haephaistoss/LoginScreen-by-Mordred):** Preservation of Mordred's 2014 custom 3D login screen framework, supporting `allFiles.exe` loose folder loading, 4GB VRAM allocation patching, and dynamic account/realmlist switching in `Config.wtf`.
- **[wowdecomp](https://github.com/haephaistoss/wow-wotlk-335-decompiled):** C++ decompilation of the 12340 binary matching original addresses (`// OFFSET:`), targeting modern 64-bit builds on macOS (Apple Silicon Metal via WoWReMac), Linux, and WebAssembly.
- **Combat Mechanics & Spell Notes:** A personal archive detailing 3.3.5a spell batching delays, diminishing returns, proc coefficients, and aura stacking interactions. Having played arena up to 2822 rating in Season 6 and hosted community tournaments, I occasionally consult with private server teams on debugging combat formulas and core stability.

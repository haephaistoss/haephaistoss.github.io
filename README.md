## 🏛️ Featured Works & Projects

### 1. [Lasthavens AddOn & LAN Bridge](https://github.com/haephaistoss)
*Universal Cross-Platform Companion Daemon & Chromium Extension*
- Integrates local 3.3.5a AddOns (300+) and WTF accounts (33) directly with the in-browser WebAssembly client (`lasthavens.com`).
- Zero-configuration LAN sharing (`0.0.0.0:8443` with dynamic IP detection for iPad, iPhone, laptops).
- Native system file chooser dialogs on macOS (`osascript`), Windows (`FolderBrowserDialog`), and Linux (`zenity`/`kdialog`).
- High-performance dynamic WebVfs indexing for 22,000+ files with live ping latency monitoring.
- 1-click automated SavedVariables cloud synchronization.

### 2. [LoginScreen-by-Mordred](https://github.com/haephaistoss/LoginScreen-by-Mordred)
*Iconic 2014 Custom 3D Login Screen Engine Preservation*
- Binary unlocked `allFiles.exe` (12340) engine allowing direct loose directory trees (`PATCH-V.MPQ`) without packing MPQs.
- Modded for 4GB Large Address Aware (LAA) VRAM allocation.
- Custom dynamic LUA account password and multi-realmlist switcher saving directly into `WTF/Config.wtf`.

### 3. [wowdecomp](https://github.com/haephaistoss/wow-wotlk-335-decompiled)
*WoW 3.3.5a (12340) C++ Decompilation & Native Apple Silicon Port*
- Reconstructed 24,500+ ported functions (90.3%+ coverage) with exact original binary `// OFFSET:` tracking.
- Native 64-bit cross-compilation pipeline: Apple Silicon (ARM64 Metal / `WoWReMac`), Linux 64-bit, and WebAssembly browser runtime.
